6. 붙이는 법 — 전부 말로

법령을 검색하고 조문을 확인할 수 있는 MCP 도구를 설치해줘.
이 저장소를 클론해서 설치해줘 — https://github.com/parkjui92/deident 설치가 끝나면 무엇을 할 수 있는지, 어떻게 부르는지 알려줘.
Crossref API로 최근 3년 science and technology policy 논문을 연도별로 집계해서 표로 보여줘.
키가 필요한 창구는 .env 파일에 키를 두고 에이전트가 읽게 한다 — 문서 · 채팅 · 슬라이드에 키를 적지 않는다. 설치가 안 되면 오류 메시지를 그대로 붙여 넣고 "왜 안 되는지 설명하고 고쳐줘"

7. 사용 팁 — 키 보관과 보안 검토

팁어떻게
API 키는 .env에프로젝트 폴더의 .env 파일에 LAW_OC=… 식으로 한 줄씩 적고 에이전트가 읽게 한다. 문서 · 채팅 · 슬라이드 · 깃허브에는 절대 적지 않는다 — .gitignore에 .env를 넣어 저장소에 올라가지 않게
설치 전 적대적 보안 검토남이 만든 MCP · 스킬 · 플러그인은 설치 전에 공격자의 눈으로 읽힌다 — 어떤 권한을 요구하는지, 어디로 네트워크를 보내는지, 파일을 지우거나 키를 읽는 코드가 있는지. 아래 프롬프트를 그대로
설치 후 확인은 일을 시켜서"설치됐다"는 말이 아니라 "방금 설치한 도구로 ○○ 해줘"의 결과로 확인 — 안 되면 오류 메시지를 그대로 붙여 넣기
권한 창은 읽고 허용파일 쓰기 · 명령 실행마다 뜨는 창이 안전장치 — 습관적으로 누르지 않는다. 중요한 폴더는 복사본에서 작업
기관 자료는 반입 규칙부터미공개 과제 · 평가 원자료 · 개인정보 원본은 넣지 않는다. 명단 · 계획서는 deident로 비식별한 뒤에
